# Ian Xiaohei Illustrations

中文小黑怪诞正文配图生成 Skill | 16:9 白底手绘 | 少量红橙蓝批注 | Codex Skill

## 概述

Ian Xiaohei Illustrations 是一个 Codex Skill，用来指导 AI Agent 为中文文章、帖子、博客、Notion 文档和方法论内容生成正文配图。

核心目标：先理解文章里的认知锚点，再把其中一个判断、流程、结构、状态或隐喻，变成一张有记忆点的 16:9 手绘解释图。

**一句话：** 让 AI 不只是"配一张图"，而是把文章里的一个关键认知动作画出来。

## 核心特点

- **视觉 IP 小黑**：黑色实心、白点眼、细腿、空表情的小角色，是正在认真参与系统运转的荒诞工作者，不是装饰
- **纯白背景**：不要纸纹、米色、阴影、渐变
- **手绘风格**：黑色细线、轻微抖动、大量留白
- **少量批注**：红色（关键警告/问题/结果）、橙色（主流向/路径/箭头）、蓝色（次要备注/反馈/系统状态）
- **16:9 横版**：正文配图标准比例

## 适用场景

适合：知识型内容、方法论内容、AI 工作流内容的正文配图；想把抽象判断画成具体隐喻；需要比 PPT 信息图更轻、更怪、更有个人识别度的风格。

不适合：商业插画、品牌 KV、传统 PPT 信息图、儿童卡通、表情包风格。

## 小黑 IP 形象

| 属性 | 描述 |
|------|------|
| 外形 | 黑色实心小怪物，白色圆点眼睛，细腿，身体可是圆柱/黑豆/黑盒/漏斗/影子/洞口 |
| 表情 | 空、呆、冷静、认真 |
| 性格 | 很认真但做的事有点荒诞，像低调的系统操作员，冷幽默不卖萌 |
| 职责 | 搬运素材、拉线汇聚、卡在断点里、操作判断杆、筛选漏斗、搬砖搭桥 |
| 禁止 | 可爱吉祥物、儿童卡通、复杂服装、闪亮眼睛、只是站在角落看 |

**判断标准：** 如果去掉小黑，图的核心隐喻还能完全成立，说明小黑太装饰了。

## 八种构图模式

1. **Workflow 流程** — 输入->处理->输出，左侧输入/中间处理/右侧输出/橙色箭头
2. **系统局部** — 只画 3-5 个核心模块，小黑参与其中一个关键动作
3. **前后对比** — 左混乱右稳定，中间橙色箭头
4. **角色状态** — 2-4 个小状态，每个状态一个短标注
5. **概念隐喻** — 一个大的怪物件或机器，少量输入一个输出
6. **方法分层** — 一层层盒子，小黑在旁边搬砖或搭建
7. **地图路线** — 弯曲路径，少量节点，小黑牵线或走路
8. **小漫画分镜** — 2-4 个小场景，每格只表达一个动作

## 工作流程

1. 读取文章内容
2. 提炼核心观点、认知转折、流程结构
3. 先输出 shot list：每张图只选一个认知锚点
4. 选择结构类型
5. 重新发明低科技、怪诞但成立的物理隐喻
6. 让小黑承担核心动作
7. 每张图单独调用图像模型生成
8. 按 QA checklist 检查
9. 保存最终 PNG
